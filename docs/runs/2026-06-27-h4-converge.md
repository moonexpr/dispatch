## Finding — `test-approval.sh` is a stale harness, not a product regression

`scripts/demo/test-approval.sh` drives three shell scripts that **no longer exist** in the tree:
`scripts/architect-intake.sh`, `scripts/fix-dispatch.sh`, `scripts/closure.sh`. They were retired
in the BaseWorkflow / grounded-replacement pivot (admin approval, fix-ladder, and closure logic
moved into the YAML engine + Python). The harness still `bash "${ROOT}/scripts/<name>.sh"`s them,
so every assertion that shells out returns exit **127** (command-not-found) → 21 false failures.

The behaviour the harness *intends* to cover (approval ladder, fix-attempt tiers
gen-local→gen-default→gen-frontier, closure gate) is exercised by `smoke.sh` (green) and the engine
e2e (green). **No live regression.** The harness itself needs to be retired or re-pointed at the new
engine — squarely within the shell-retirement work tracked in **#158**.
